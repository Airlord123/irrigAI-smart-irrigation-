# irrigAI-smart-irrigation-
An IoT-enabled smart agriculture system built around the ESP32-S3-WROOM-1-N8R8, designed for real-time farm monitoring, automated irrigation, and Edge AI-based decision making. The system integrates DHT22 temperature/humidity and soil-moisture sensors to continuously monitor environmental and soil conditions.

The ESP32-S3 processes sensor data locally and can automatically control the water pump based on soil moisture and environmental conditions, preventing unnecessary irrigation. The system also supports local data logging, wireless/cloud monitoring, and on-device Edge AI, enabling farm-specific analysis and intelligent irrigation recommendations with reduced cloud dependency.

Technologies: ESP32-S3 • Embedded C • DHT22 • Soil Moisture Sensor • ADC • I2C • SPI • GPIO • Edge AI/ML • IoT • Automated Irrigation • Data Logging.
